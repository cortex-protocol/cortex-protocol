## ⚡ 1-Minute Installation Guide (Chrome / Brave / Edge / Opera)

1. **Download & Extract**:
   * Download `cortex-wallet-extension.zip`.
   * Unzip / Extract the folder onto your computer.

2. **Open Extensions in your Browser**:
   * **Chrome / Brave**: Go to `chrome://extensions/`
   * **Edge**: Go to `edge://extensions/`

3. **Enable Developer Mode**:
   * Toggle **"Developer mode"** (Mode développeur) in the top-right corner.

4. **Load the Extension**:
   * Click **"Load unpacked"** (Charger l'extension non empaquetée).
   * Select the extracted `cortex-extension` folder.
   * Pin the **Cortex Wallet** icon 🧠 to your browser bar!
